# Musgo y Lumbre

Juego de estrategia 3D de bandera oculta, para un jugador contra IA, con ambientación de bosque acogedora. Un único `index.html` estático: sin build ni backend.

Carga three.js (cdnjs) y las fuentes (Google Fonts) desde CDN.
